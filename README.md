# Firestorm-TWW-Tools · 魔兽世界 TWW 窗口监控与断线自动重连 / 采集时速统计工具

专为 **World of Warcraft 11.2.5.63704 (The War Within - Firestorm)** 设计的高性能 C# WinForms 桌面监控工具。支持单开与多开窗口独立监控、自动化掉线重连处理、角色内存数据实时读取、背包矿草存量监控与每小时采集效率统计。

---

## 🌟 核心特性

### 1. 自动化断线重连 (三段式自动化闭环)
- **精准掉线识别**：通过内存 `ObjectManager` 与本地玩家指针实时校验在线状态，支持配置防抖延时（默认 3 秒）过滤卡顿假掉线。
- **三段式重连动作**：
  1. **关闭弹窗**：识别“已从服务器断开连接”弹窗，优先调用 Glue 界面 Call / Lua 接口，并保底向游戏窗口后台发送回车（`VK_RETURN`）。
  2. **触发重连**：在账号登录界面优先调用 `Reconnect()` 或后台发送回车触发重连。
  3. **进入游戏**：在角色选择界面优先调用 `EnterWorld()` 或后台发送回车进入当前默认/高亮角色。
- **纯后台运作**：无需置顶抢夺前台焦点，使用 `PostMessage` 配合硬件级扫描码（ScanCode），不影响用户正常使用电脑。

### 2. 进程管理与轻量紧凑设计 (针对最多6开优化)
- **关闭/结束进程**：顶部工具栏与右键菜单新增“❌ 关闭进程”功能，支持弹窗确认后先优雅关闭窗口，若超时未退出则强制终止该游戏进程并自动清理监控会话。
- **极速增量刷新 (彻底杜绝闪烁)**：重构列表刷新机制，采用原地 Diff 增量同步与双缓冲（DoubleBuffered），定时扫描或手动刷新时绝不重置列表、不跳动滚动条、不丢失当前选中焦点。
- **紧凑面板设计**：针对多开（最多 6 个进程）深度精简窗口体积（880×560，最小 800×480），更轻巧省屏。

### 3. 角色数据与状态监控
- **真实角色名直读**：基址直读客户端全局角色名偏移（`0x47F98B0`），杜绝乱码与 `0`。
- **核心数据读取**：实时读取角色等级（`6960`）、当前生命值与最大生命值（`6944`）、世界实时三维坐标 (X, Y, Z)。
- **多开无缝管理**：自动扫描所有运行中的客户端（`WoW 11.2.5 - Firestorm.exe` 等），在多开列表中独立展示每个窗口的 PID、角色、等级、在线状态与累计重连次数。

### 3. 背包矿草监控与采集时速 (Items/Hour)
- **内置 TWW 专属预设**：
  - **矿石**：铋矿石 (210796)、亚基矿石 (210806)、铁爪矿石 (210802)、虚空石 (210804)
  - **草药**：菌柄 (210798)、荷草 (210800)、心绽花 (210799)、诱毒之花 (210801)
- **自定义物品支持**：可在界面自由输入名称与 ID，实时增删监控条目。
- **时速精确计算**：自动记录监控开始时间与初始存量，实时计算单品采集增量、单品时速（个/小时）、总收获量与综合采集时速。
- **手动存量修正**：支持一键手动修正或录入当前真实存量。

## 🚀 快速启动

### 方式一：一键启动脚本
直接双击运行仓库根目录下的：
```cmd
run.bat
```
或重新编译：
```cmd
build.bat
```

### 方式二：命令行编译与运行
```powershell
# 编译 Release
dotnet build -c Release

# 启动程序
.\bin\Release\net8.0-windows\FirestormTwwMonitor.exe
```

### 运行单元测试
```powershell
dotnet test tests/FirestormTwwMonitor.Tests.csproj
```

## 🖥 界面使用指南

1. **顶部控制栏**：
   - **🔍 刷新进程**：手动立即扫描所有 WoW 窗口（后台亦每 5 秒自动发现新开窗口）。
   - **▶ 全部开启监控**：对当前列表中的所有 WoW 窗口一键开启掉线重连与数据监控。
   - **⏹ 全部停止**：一键暂停所有窗口的监控。
2. **左侧窗口列表**：
   - 选中某个窗口后，右侧面板将即时切换到该窗口的实时状态与采集看板。
   - **右键菜单**：支持单独启动/停止该窗口监控、一键置顶激活窗口、后台发送回车测试。
3. **右侧上部 (角色与重连设置)**：
   - 查看角色名、等级、血量、坐标与在线指示灯。
   - 配置“开启自动重连”、“掉线确认延时(秒)”、“动作重试间隔(秒)”。
4. **右侧下部 (采集看板)**：
   - 点击 **▶ 开始统计** 启动计时并锁定初始数量基线。
   - 点击 **🔄 重置统计** 重新开始采集速率计算。
   - 在底栏输入名称与 ID 可随时新增自定义矿草，点击“✏️ 更新存量”可手动校准。
5. **底部日志框**：
   - 记录重连流程的每个阶段状态与操作细节。
