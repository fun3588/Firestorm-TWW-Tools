# Firestorm-TWW-Tools · 魔兽世界 TWW 窗口监控与断线自动重连 / 采集时速统计工具

专为 **World of Warcraft 11.2.5.63704 (The War Within - Firestorm)** 设计的高性能桌面监控工具。支持单开与多开（最多6开或更多）独立监控、自动化掉线重连处理、角色内存数据实时直读、背包矿草存量监控与每小时采集效率统计。

本项目提供 **双版本** 实现：
1. **C++ 原生原生极速版 (`FirestormTwwMonitor_Cpp.exe`)**：纯 Win32 原生界面，零运行时依赖，专用内存 < 6MB，CPU 占用 < 0.05%，极致轻量。
2. **C# WinForms 完整版 (`FirestormTwwMonitor.exe`)**：基于 .NET 8，界面丰富现代化。

## 🌟 核心特性

### 1. 自动化断线重连 (100% 纯后台双保险机制)
- **精准掉线与选角识别**：
  - 核心依据基址全局角色名（`OFF_NAME_GLOBAL = 0x47F98B0`）与世界内状态权威判定。
  - **在选角界面（未选角/待进游戏）、载入界面或断线界面，全局名字必定为空**，100% 精准识别为“待进游戏（未在线）”，杜绝历史指针缓存误判。
- **纯后台双保险重连动作**：
  1. **唤醒与键盘**：后台向魔兽渲染主窗口（`GxWindowClass`）投递 `WM_ACTIVATE (WA_ACTIVE=1)` 与 `WM_SETFOCUS` 消息，配合 `WM_KEYDOWN` + `WM_CHAR ('\r')` + `WM_KEYUP` 发送回车。
  2. **底部按钮相对比例点击**：间隔 80ms 自动向角色选择界面底部中间【进入魔兽世界】按钮（相对客户区 `50%, 92%`）发送后台左键点击形成双保险。
  3. **最小化静默还原**：如果客户端被最小化，通过 `SW_SHOWNOACTIVATE` 在后台恢复尺寸，保证客户区尺寸与点击坐标计算准确，**全程不抢占当前前台窗口焦点，不移动鼠标指针**。
- **4秒自动重试机制**：默认每隔 4 秒自动重试发送后台回车与按钮点击，直至内存检测到角色正式进入世界、全局角色名生效。

### 2. 进程管理与轻量紧凑设计 (针对最多6开优化)
- **关闭/结束进程**：顶部工具栏与右键菜单提供“❌ 关闭选中客户端”功能，先优雅通知窗口关闭，超时则强制终止并清理监控。
- **极速增量刷新 (彻底杜绝闪烁)**：重构列表刷新机制，采用原地 Diff 增量同步与双缓冲（DoubleBuffered），定时扫描或手动刷新时绝不重置列表、不跳动滚动条、不丢失当前选中焦点。
- **紧凑面板设计**：针对多开（最多 6 个进程）深度精简窗口体积（880×580，最小 820×500），更轻巧省屏。

### 3. 角色数据与状态监控
- **真实角色名直读**：基址直读客户端全局角色名偏移（`0x47F98B0`），选角界面准确识别为“未选角(待进游戏)”，在线状态标识为“⏳ 待进游戏(未在线)”。
- **核心数据读取**：实时读取角色等级（`6960`）、当前生命值与最大生命值（`6944`）、世界实时三维坐标 (X, Y, Z)。
- **多开无缝管理**：自动扫描所有运行中的客户端（`WoW 11.2.5 - Firestorm.exe` 等），在多开列表中独立展示每个窗口的 PID、角色、等级、在线状态、重连状态、重连次数与背包采集数据。

### 4. 背包矿草监控与采集时速 (Items/Hour)
- **内置 TWW 专属预设**：
  - **矿石**：铋矿石 (210210)、铁爪矿石 (210214)、亚基矿石 (212234)、虚空石 (212450)
  - **草药**：菌柄 (210259)、荷草 (210242)、心绽花 (212175)、诱毒之花 (204443)、阿拉索之矛 (223847)
- **多版本兼顾**：内建 MoP、DF、SL 矿草物品目录，自动发现并聚合统计。
- **时速精确计算**：自动记录监控开始时间与初始存量，实时计算单品采集增量、单品时速（个/小时）、总收获量与综合采集时速。

## 🚀 快速启动

### 方式一：C++ 原生极速版 (推荐，超低内存与CPU)
```powershell
# 使用 CMake 编译 (需要 GCC / MinGW 或 MSVC)
cmake -B build_cpp -G "Ninja" -DCMAKE_BUILD_TYPE=Release
cmake --build build_cpp --config Release

# 启动原生极速版程序
.\build_cpp\bin\FirestormTwwMonitor_Cpp.exe
```

### 方式二：C# WinForms 版 (一键启动或命令行)
直接双击运行根目录下的 `run.bat`，或通过命令行：
```powershell
# 编译 Release
dotnet build -c Release

# 启动程序
.\bin\Release\net8.0-windows\FirestormTwwMonitor.exe
```

### 运行单元测试
```powershell
dotnet test tests/FirestormTwwMonitor.Tests.csproj
```

## 🖥 界面使用指南

1. **顶部控制栏**：
   - **🔍 刷新进程**：手动立即扫描所有 WoW 窗口（后台亦每 5 秒自动发现新开窗口）。
   - **▶ 全部开启监控**：对当前列表中的所有 WoW 窗口一键开启掉线重连与数据监控。
   - **⏹ 全部停止**：一键暂停所有窗口的监控。
2. **左侧窗口列表**：
   - 选中某个窗口后，右侧面板将即时切换到该窗口的实时状态与采集看板。
   - **右键菜单**：支持单独启动/停止该窗口监控、一键置顶激活窗口、后台发送回车测试。
3. **右侧上部 (角色与重连设置)**：
   - 查看角色名、等级、血量、坐标与在线指示灯。
   - 配置“开启自动重连”、“掉线确认延时(秒)”、“动作重试间隔(秒)”。
4. **右侧下部 (采集看板)**：
   - 点击 **▶ 开始统计** 启动计时并锁定初始数量基线。
   - 点击 **🔄 重置统计** 重新开始采集速率计算。
   - 在底栏输入名称与 ID 可随时新增自定义矿草，点击“✏️ 更新存量”可手动校准。
5. **底部日志框**：
   - 记录重连流程的每个阶段状态与操作细节。
